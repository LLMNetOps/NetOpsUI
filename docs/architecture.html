Approval / Interrupt Flow
1 Supervisor route query → config_agent (Joko)
2 Agent panggil write tool: run_command_write atau backup_router_config
3 interrupt() — eksekusi PAUSE
4 TUI tampilkan approval prompt ke operator
5 Operator tekan Y atau N
6 resume_after_approval() → graph.stream() lanjut
7 Tool execute → tool berikutnya atau END. Interrupt selanjutnya tetap propagate.
Safety Mechanisms · agents/nodes.py

Safety Net Final msg bukan AIMessage → fallback ke ToolMessage terpanjang

Blocklist R run_command tolak keyword destruktif
