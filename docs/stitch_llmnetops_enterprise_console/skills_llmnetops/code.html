Network Health Check Logic

Intent

Analyze latency spikes and identify bottlenecks across enterprise spine-leaf architecture.

Instructions

  1. When a trigger keyword is detected, query NetBox for the relevant device IP.
  2. Execute ssh_exec with show interface counters to identify errors.

  4. Compare current output with the baseline stored in the metrics database.

Constraints
